## 2. Distinctions obligatoires

### Modes sombres ≠ secteur sombre ≠ résidu sombre

- **Modes sombres** : problème d'observabilité d'un mode individuel ou spectral.
- **Secteur sombre arithmétique** : stratégie générale de triangulation de l'information perdue.
- **Résidu sombre** : mécanisme précis où de grosses contributions de signes opposés s'annulent et où le petit reliquat porte le signe ou l'inertie finale.

### Compression fertile ≠ preuve par éléments finis

Une compression finie peut produire un témoin de signe, de rang ou d'inertie. Elle ne transforme pas une vérification numérique finie en preuve d'un énoncé asymptotique. Le travail numérique 2026 sur l'opérateur de forme quadratique de Weil réalise précisément une discrétisation P1 et insiste lui-même sur l'absence de preuve de RH.

## 3. Métaphore active actuelle : la serrure sombre

La séquence expérimentale V6 peut désormais être racontée sans perdre la définition mathématique :

\[
\boxed{
\text{TOMO} \to \text{PRIME-LOCK} \to \text{DUAL-LOCK} \to \text{RÉSIDU SOMBRE}
}
\]

- TOMO demande **quel observable voit quelque chose** ;
- PRIME-LOCK vérifie **la clé locale eulérienne** ;
- DUAL-LOCK teste **l'emboîtement local/global** ;
- le Résidu sombre mesure **ce qui reste après leur cancellation** et porte éventuellement le signe d'inertie.

La métaphore n'est autorisée que parce que chacune de ces étapes possède désormais un objet calculable et un crash-test.

## 4. Règle de promotion

Une nouvelle métaphore passe de `IDÉE` à `MÉCANISME V6` seulement si elle fournit :

1. une définition exacte ;
2. une correspondance interdite explicite ;
3. un observable ;
4. un témoin négatif ;
5. une règle d'arrêt ;
6. au moins un test reproductible ou un lemme démontré.

Le registre ci-dessus est la référence canonique pour les noms V6.

## Mise à jour V6.3a — Résidu sombre

**Statut : SURVIT, QUANTIFICATION RÉVISÉE.**  
Le mécanisme de cancellation reste observable après normalisation de Gram, mais les facteurs V6.3 calculés dans la métrique euclidienne de coefficients ne sont plus canoniques. Les valeurs à utiliser sont celles obtenues avec le vecteur propre généralisé \(Mv=\lambda Gv\), \(v^TGv=1\). Le registre doit désormais distinguer :

- **inertie / signe** : observable principal ;
- **amplification sombre** : observable secondaire, seulement après contrôle du conditionnement ;
- **magnitudes de valeurs propres ordinaires** : non interprétables quantitativement dans une base mal conditionnée.
