# Referee simulations — rôle et limites

Ce dossier contient des **simulations internes de referee**. Elles ne remplacent pas une expertise indépendante et ne doivent pas être présentées comme une validation par les pairs.

Objectif : attaquer les énoncés A, B et C comme le ferait un rapporteur hostile mais constructif, en séparant :

- les points qui paraissent corrects ;
- les lemmes classiques qui exigent une citation exacte ;
- les passages qui demandent une rédaction supplémentaire ;
- les hypothèses conditionnelles ;
- les questions de priorité / nouveauté.

Ordre recommandé :

1. `REFEREE_A.md` — Théorème A, exposant d'énergie et `Theta`.
2. `REFEREE_B.md` — Théorème B sous RH.
3. `REFEREE_C.md` — termes inférieurs / presque-périodicité.
4. `REFEREE_INSTRUCTIONS.md` — protocole pour une lecture indépendante.
5. `REFEREE_SUMMARY.md` — verdict consolidé de cette simulation.
