# Zone de dépôt

Chaque fiche de tâche a ici son dossier `TAC-xxx/`. Le producteur n'écrit que dans ce dossier : `RAPPORT.md` obligatoire (sections Prévision, Méthode, Résultat, Portée, Critère de rejet, Statut proposé), avec les programmes, données et journaux utiles. Le vérificateur écrit dans `TAC-xxx/verification/VERIFICATION.md`.

Rien de ce qui est ici ne fait partie de l'état publié du corpus tant que l'auteur n'a pas accepté la fiche et que ses pièces n'ont pas été intégrées selon le protocole du pilotage. Procédure : [CIBLAGE.md](../Pilotage/CIBLAGE.md).

*Deposit area. Each task card has its folder `TAC-xxx/` here; nothing here belongs to the published corpus until the author accepts it. Procedure: [TARGETING_EN.md](../Pilotage/TARGETING_EN.md).*
